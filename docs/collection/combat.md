# Événements Combat

Exchange `combat.events` (topic durable); publier les faits de combat persistés. Types partagés : [contrat commun](contrat-commun.md).

| Clé de routage / message | Déclencheur et champs | Fixture JSON |
|---|---|---|
| `combat.combat-started.v1` / `CombatStarted` | Combat activé et snapshot persisté. `combat_id`, `dungeon_id`, `game_session_id`, `room_id: string` GUID requis; `participants: repeated Actor` et `monsters: repeated MonsterSnapshot` non vides; instance monster unique. Snapshot: IDs string GUID, `level: optional uint32` présent >=1; `rank: MonsterRank` = `MONSTER_RANK_NORMAL`, `MONSTER_RANK_MINI_BOSS`, `MONSTER_RANK_BOSS`. | [combat-started](../fixtures/us-collecte-01/combat-started.json) |
| `combat.skill-used.v1` / `SkillUsed` | Compétence exécutée; esquive incluse, commande refusée exclue. `combat_id`, `command_id`, `skill_id: string` GUID; `actor: Actor`; `turn_number: optional uint32` présent >=1; `targets: repeated SkillTarget` non vide; `mana_spent: optional uint64` présent, points entiers >=0. Target: exactement `hero_id` ou `monster_instance_id` string GUID et `resolution: TargetResolution` = `TARGET_RESOLUTION_APPLIED` ou `TARGET_RESOLUTION_DODGED`. | [skill-positive](../fixtures/us-collecte-01/skill-positive.json), [skill-zero](../fixtures/us-collecte-01/skill-zero.json), [skill-dodged](../fixtures/us-collecte-01/skill-dodged.json) |
| `combat.combat-ended.v1` / `CombatResult` | Résultat terminal persisté. `combat_id`, `dungeon_id`, `game_session_id: string` GUID; `outcome: CombatOutcome` = `COMBAT_OUTCOME_WON`/`COMBAT_OUTCOME_LOST`; `participants: repeated Actor`, `monster_results: repeated MonsterResult` non vides, instances uniques; `started_at`, `ended_at: Timestamp` requis UTC, fin >= début; `turn_count: optional uint32` présent >=0. `MonsterResult` requiert `monster: MonsterSnapshot`, `outcome: MonsterOutcome` = `MONSTER_OUTCOME_DEFEATED`/`MONSTER_OUTCOME_SURVIVED`. | [combat-ended-won](../fixtures/us-collecte-01/combat-ended-won.json), [combat-ended-lost](../fixtures/us-collecte-01/combat-ended-lost.json) |
| `combat.consumable-used.v1` / `ConsumableUsed` | Consommable appliqué au combat. `combat_id`, `command_id: string` GUID; `actor: Actor`; `item: ItemReference`; `quantity: optional uint32` présent >0, item instancié => 1. | [consumable-used](../fixtures/us-collecte-01/consumable-used.json) |
| `combat.combat-completed.v1` / `CombatCompleted` | Prérequis terminal accepté par Dungeon; Rewards confirme seulement une victoire. `result: CombatResult` requis; `dungeon_acceptance_id: string` GUID requis victoire/défaite; `rewards_confirmation_id: optional string` GUID requis victoire, absent défaite. Ne porte aucune attribution XP; `result.ended_at` garde l'heure terminale. | [combat-completed-won](../fixtures/us-collecte-01/combat-completed-won.json), [combat-completed-lost](../fixtures/us-collecte-01/combat-completed-lost.json) |
